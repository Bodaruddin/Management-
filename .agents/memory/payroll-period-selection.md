---
name: Payroll period selection
description: The admin payroll flow must allow selecting a month and year.
---

Admin payroll calculation must remain selectable across past months and years; do not narrow it to fixed current- or previous-month actions.

**Why:** The user corrected a previous-month-only shortcut and asked to select a month.

**How to apply:** When modifying admin payroll calculation, preserve month/year selection and calculate the selected period.
